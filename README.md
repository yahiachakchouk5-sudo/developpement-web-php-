# Univ Clubs

Application web de gestion des clubs universitaires, développée en PHP avec MySQL.

## Fonctionnalités

- Connexion et gestion des utilisateurs
- Création et gestion des clubs
- Espace administrateur

## Technologies

- PHP
- MySQL
- HTML / CSS / JavaScript

## Installation

1. Cloner le dépôt :
   git clone https://github.com/yahiachakchouk5-sudo/NOM-DU-DEPOT.git
2. Placer le dossier dans `htdocs` (XAMPP) ou `www` (WAMP)
3. Importer la base de données avec le fichier `univ_clubs.sql` dans phpMyAdmin
4. Configurer la connexion dans le dossier `config`
5. Ouvrir `http://localhost/NOM-DU-DOSSIER` dans le navigateur
